競馬予想ノート

過去の結果 × 新聞 × パドックで予想
枠馬番馬名性齢斤量騎手調教師 馬体重増減単勝人気印パドック着順

入力は自動で保存されます。印の欄は新聞の印を左から並べて入力（例：◎○-△）。レースが終わったら着順を入れると、次の予想の学習データになります。取消は着順に「取」。

競馬新聞の写真から読み取る

新聞の馬柱・出馬表を撮った写真（複数可）を選ぶと、AI が馬名・騎手・オッズ・記者の印・過去走を読み取り、出走表に反映します。

パドックの写真・動画で評価する

馬を選んでその馬の写真・動画を読み込むか、「全頭」でパドック全体の動画を読み込みます（ゼッケン番号で見分けます）。動画は数枚の場面に分けて評価します。AI の評価は参考値として予想に少し反映されます。自分の目で見た評価は出走表の「パドック」欄（A〜E）へ。

過去のレース結果

予想は、ここに入っている過去の結果（着順・オッズ・上がり・騎手など）から学習します。CSV で取り込めます（1 行 = 1 頭）。

CSV の列

1 行目に列名を入れてください（順番は自由。英語名でも可）。

日付, 区分(中央/地方), 競馬場, R, レース名, 芝ダ, 距離, 馬場, クラス, 馬番, 枠, 馬名, 性齢, 斤量, 騎手, 調教師, 馬体重, 増減, 単勝, 人気, 着順, タイム, 上り, 複勝

必須は「日付・競馬場・R・馬番・馬名」。着順が入っているレースが学習に使われます。単勝（確定オッズ）と複勝の払戻倍率があると回収率も検証できます。

この日のレース

過去の結果で検証・学習

結果の入ったレースを古い順に並べ、前の 7 割で重みを学習し、残り 3 割を「当時の情報だけ」で予想して成績を測ります。1 番人気を買い続けた場合と比べられます。

AI（写真・動画の読み取り）

新聞の写真読み取りとパドック評価に Anthropic の Claude API を使います。API キーは Claude Console で発行できます（利用料がかかります）。キーはこの端末のブラウザ内にだけ保存されます。共用の端末では保存しないでください。

注意

このツールの予想は過去データから計算した目安です。的中や利益を保証するものではありません。馬券は余裕のある範囲で楽しんでください。

表を貼り付け

Excel・スプレッドシート・CSV からコピーした表を貼り付けます。1 行目は列名（馬番, 馬名, 騎手, 単勝 など）。
